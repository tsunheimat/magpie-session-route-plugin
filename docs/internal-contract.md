# Internal implementation contract

Integration contract for API version 1. No raw gateway JSON crosses the API. Missing measurements are null or absent according to the endpoint's schema; unknown is never synthesized as zero. This contract includes the v0.3.1 project/actor/provider corrections, v0.3.2 nested-row presentation and v0.3.3 client/model-only child display; see [validation](validation.md) for verification evidence and remaining limitations.

## Normalized records

`Request`:
- `key` (generation-namespaced string), `id` (original numeric trace/ledger route ID or null), `time` (ISO), `updatedAt` (ISO), `sessionKey` (encoded exact agent/session tuple or null), `agent`, `session` (native recorded ID or null), `parentSessionKey` (confirmed same-agent only or null), `subagentId` (safe actor identifier or null), `isSubagent` (boolean), `model` (requested), `servedModel` (nullable), `provider` (nullable actual/known provider), `effort` (nullable), `folder` (optional opt-in), `group` (safe `{id,name}` or null).
- `done` boolean, `status` integer|null, `outcome` one of `in-flight`, `success`, `failed`, `unknown`, `unavailable`; `error` a fixed safe diagnostic label|null, never raw error text.
- `ms`, `ttft`, `tokens`, `inputTokens`, `outputTokens`, `cacheReadTokens`, `cacheWriteTokens`, `reasoningTokens`, `cost`: number|null. `priced` boolean. `cost` is unavailable in raw trace. `retries`, `fallbacks`: number|null.
- `candidates`: ordered `{key,provider,model,effort,label,state}`. `key` opaque, `label` neutral account/key label. `state` distinguishes candidate/attempting/success/failed. No raw seat IDs/account emails.
- `attempts`: ordered `{index,candidateKey,provider,model,effort,servedModel,start,done,status,outcome,ms,ttft,error,transition}`. `transition`: `initial`|`retry`|`fallback`|`unknown`. Preserve incomplete evidence; no predicted tries.
- `partial` boolean, `reasons` fixed string array. Historical request may have empty candidates/attempts, with a reason that attempt history is unavailable. Optional `isIndependentSubagent` boolean (default false) is true only when documented identity evidence proves a child owns the native session being selected, rather than sharing a parent's header; direct-only filtering may include that child's own traffic while preserving its `isSubagent` classification. History joins establish this from validated native-child evidence, never from actor absence or heuristic IDs.

`Session`: `{key,agent,displayId,title:null,folder:null|string,lastActivity,activeRequests,requestCount,lastModel,lastProvider,parentKey:null|string,isChild:boolean}`. Native title is not available. Use source-scoped counts; unknown traffic is never a session.

`Metrics`: `{requests,inFlight,failed,retries,fallbacks,averageTTFT,ttftSamples,tokens,inputTokens,outputTokens,cost,pricedRequests,unpricedRequests,partial}`. Null is unavailable; `cost` is a known subtotal only if at least one priced record exists, and partial pricing remains marked. Timings in ms; costs as reported ledger USD. No guessing prices.

`Connection`: `{status,lastUpdated,reason,gatewayVersion}`. Status is `starting`|`live`|`stale`|`disconnected`|`incompatible`|`stopped`. `lastUpdated` ISO|null; `reason` safe string|null.

`Coverage`: `{source:'trace'|'ledger',period,label,partial,reasons,retained?,scanned?,available?,snapshotAt?}`. Every displayed total cites it.

`State`: `{apiVersion:1,instanceId,generation,revision,seq,scope,connection,coverage,sessions,unknownRequests,requests,metrics,graph:{requestKeys}}`. `requests` can contain historical `handed_on_only` evidence; such records contribute recorded usage but never request, failure, in-flight, session-request or unknown-request counts. Pagination counts evidence records, not requests. The complete serialized response (including sessions, graph and envelope) must fit the byte limit; trimming retains whole records, recomputes derived fields and marks partial coverage. A live selection is validated against the authoritative retained cache, not the byte-trimmed All response.

`scope` uses shared parseScope: `{kind:'all'|'session'|'unknown',sessionKey:null|string,includeChildren:boolean,period:'live'|'today'|'7d'|'30d'}`. All means all actors, regardless of includeChildren. Session direct-only excludes known subordinate actors. Missing session => ApiError(410,'session_expired',safe message), never implicit all. Only fresh authoritative data permits fallback in UI.

## Native upper-block projection

The copied upper Routing block consumes a separate sanitized shape, not a renaming of the normalized `Request` above. Both projections are produced in the same `applyTrace` transaction by the one shared collector; neither the browser nor the native projector starts another gateway poller.

`NativeState`: `{apiVersion:1,instanceId,generation,revision,connection,coverage,object:'trace',now,seq,pid,serves,ids,routes,totals,lifted}`.

- `now` is the validated gateway clock, not ingestion time. `now`, `serves` and `totals` may be null. `totals` contains only observed integer fields among `requests`, `rerouted`, `errors`. Its scope is **gateway since start**, never the visible sessions or four-source stage.
- `coverage.source` is `trace`, `period` is `live`, `inventory` is `unavailable`, and `totalsScope` is `gateway_since_start` or `unavailable`. The projection is always partial relative to full configuration/history. `reasons` explains withheld, stale, bounded or absent evidence.
- `ids` names exactly the returned native routes. Unlike normalized unavailable tombstones, an evicted unfinished request is removed from the native renderer rather than kept looking live. Complete serialized envelopes, not only route arrays, obey response limits.
- Routes retain exact validated `agent` and recorded `session`, safe model/effort fields, bounded `order`/`left`/`tries`, and finite allowlisted routing/group/affinity/rest/quota/price/usage shapes. Each route carries `evidence:{partial,reasons,label}`. Missing values stay absent; unsupported routing modes are not assumed to be Smart.
- Account references use generation-local HMAC handles shared across requests/sessions and across candidates, attempts, rests and lifted-rest references. Provider/group/actor handles use separate domains. These are not the request-local `candidates[].key` of the older API. Native account/model/configured-effort dimensions remain separate seats.
- Safe recorded provider display `name` is distinct from opaque provider identity. Validate it as bounded display text, not as a key; preserve benign Unicode/punctuation, reject controls/bidi, email/URL/credential-like text, and render it only as text. Missing/unsafe names get a neutral fallback with an evidence reason. Account/key/group names remain neutral labels; raw `who` and account identifiers never cross this API.
- Provider artwork is allowed from the existing fixed native icon inventory, shared with the browser rather than inferred from a guessed brand table. Native precedence remains explicit `icon`, then `preset` only when icon is absent, then generic. Explicit unsupported artwork becomes generic, not another brand. Arbitrary `file:`, URLs, paths and unbundled icons are rejected.
- Optional `requestedModelName` is display-only: when a retained attempt and candidate agree on account ID, provider and model, and the original requested model equals that provider plus `/` plus that model, it carries the validated model without that routing prefix. It is derived before opaque provider mapping, never trusted from an input field. Reply `served` names and genuine model namespaces remain intact; unconfirmed prefixes are not guessed away. Original requested model, provider and seat identity fields remain unchanged. The child view prefers concrete served evidence, otherwise this verified requested name, otherwise the original model.
- Optional `projectName` is the validated final component of the recorded folder, controlled by `showProjectNames` (default true). It is not a repository/title lookup, and no parent path is sent unless separate `showFolders` is true. Both false withhold all project/folder display metadata. Both settings participate in installation reauthorization and service replacement.
- Optional opaque `actorId` joins documented `subagentId` and `sub` evidence in the same generation-local actor domain. Original `subagentId` remains a turn marker rather than being populated from tool-less helper calls. `isSubagent` denotes observed worker evidence; missing/conflicting actor IDs yield unknown-actor activity, not invented workers. UI actor identity includes the exact session-source key. Raw actor identifiers and generic worker ancestry are not exposed/inferred.
- Bodies, prompts, headers, archive paths, private titles, raw IDs/emails, arbitrary rule/classifier/reset/vendor text and network details remain withheld.
- No provider inventory is inferred from candidate count. Missing inventory must not be represented as an empty configuration or the native assertion that only one account is enabled. Unsupported explanations must be withheld or explicitly identified as unavailable.
- `mine` and `by` are not invented backend fields. The host adapter separately handles watchability from real connection state, without claiming ownership of the gateway process.
- A generation or backend-instance change clears native presentation state. `clear()` removes both projections and rotates opaque identity namespaces.

Source identity belongs to the small frontend patch: known sources use the exact tuple `['session',agent,session]`; unknown sources use a separate tagged generation/request/time identity. `parentSession`, folder, model and provider never reparent a known source. Multiple requests in one source keep independent native request IDs/flights. The native four-source admission policy and the separate `LIVE = 4` startup/resume request cap are unchanged.

## Backend module interfaces

- `createAggregator({limits?,clock?,instanceId?,showFolders?,showProjectNames?})` from aggregator.mjs. `applyTrace(rawEnvelope,{full=false}={})` validates/sanitizes before caching, returns `{resync:boolean}`. `setConnection({status,reason?,gatewayVersion?})`. `snapshot(scope)` returns State synchronously. `nativeSnapshot()` returns detached NativeState synchronously. `listSessions()` returns safe Session[]. `clear()`. `seq` readable cursor, `generation` readable local epoch. Initial/restart batches are full; raw batches follow actual Magpie contract. API snapshots must be detached/safe.
- `createGateway({address?,limits?,timeoutMs?})` from gateway.mjs. `hello({signal}={})` => `{name,version}`; `trace({after=0,wait=false,signal}={})` => raw validated-size JSON; `usage({period,offset=0,limit=200,signal}={})` => raw JSON. Paths fixed, usage includes `via=through&computer=this`. No caller-provided URL/headers. No ambient proxy or redirects. Raw records are immediately consumed by projection/history.
- `createCollector({gateway,aggregator,clock?,pollTimeoutMs?,backoffMs?,fullIntervalMs?})` from collector.mjs. `start()` is idempotent/nonblocking; `stop()` aborts and awaits loop. Full resnapshot on uncertain continuity; exactly one trace call at a time.
- `createHistory({gateway,aggregator,limits?,clock?})` from history.mjs. `snapshot(scope,{offset=0,limit=100,snapshotId=null,signal}={})` async => State plus `{pagination:{snapshotId,offset,limit,nextOffset,total},coverage}`. All histories share period scans independent of browser/session. Safe sessions for that period available in snapshot. Immutable bounded local snapshot IDs; expired => ApiError(409,'history_expired',...). `clear()` and `stop()` abort work. No hidden fetch on live UI refresh. Provider schema is source-inspected; match identities conservatively.
- `startService(input,options)` from lifecycle.mjs owns config/lifecycle, constructs gateway/aggregator/collector/history/server, returns nonblocking managed handle with `stop()`. Unprovisioned returns without listener/collector. Default export index.mjs delegates and returns `{}`.
- `createServer({config,aggregator,history,startCollector,authorizeInstallation,stop?,...testOverrides})` from server.mjs: runtime implementer may choose exact server factory API with lifecycle; do not change public contracts above. It calls collector only after bind and authorized use. Installation authorization is checked before all sensitive data responses, not only periodically.

## HTTP

Public fixed UI assets, `/healthz` and ownership nonce endpoint only carry non-sensitive data. Protected GET `/api/native-routing` returns NativeState and rejects every query parameter; GET `/api/state?session=<key|unknown>&period=live&includeChildren=0|1`, GET `/api/sessions` with same scope args, GET `/api/history?...&period=today|7d|30d&offset=0&limit=100&snapshot=<id>` retain their existing contracts. All sensitive routes share the lazy collector and installation revalidation before/after work. Native static assets come only from the fixed manifest; source/test-only trees are not public. CSP permits native style attributes and CSS data-image masks, not inline/eval scripts, style elements or same-origin sandbox privileges.

`/api/state` dispatches to history for non-live periods; `/api/history` is explicit paginated history. `/api/sessions` response `{apiVersion,instanceId,generation,revision,connection,coverage,sessions,unknownRequests}`. Error `{error:{code,message}}`, sanitized fixed messages, correct HTTP status. Token goes only in Authorization. `installationId`/`apiToken` options; token base64url 32 random bytes (43 chars); installationId base64url 16 bytes (22 chars). Service port default3496, `showFolders:false`, `showProjectNames:true` (new basename-disclosure default, no persisted option rewrite).

## Frontend

The frontend retains the pinned native upper Routing source, CSS, translations, helpers and artwork introduced in v0.3.0. A deterministic extraction excludes lower Requests/Groups/provider editors, body/context viewers and mutation/navigation side effects; the source patch provides session identity, project labels and source-local sub-agent activity. The v0.3.2 presentation correction replaces v0.3.1's actor-ID boxes with depth-1 native nested-group rows. Actor keys stay in the source-local JavaScript maps, not child DOM attributes, labels or tooltips. Rows show concrete observed served/requested models from active requests, or retained ended requests when none remain active; routing-group handles and missing-model substitutions are not observed models. Unknown actor evidence stays one aggregate. The v0.3.3 client/model-only correction removes visible actor labels/headings and state pills, uses the same client-icon lookup as the parent, and leaves request state/counts and unavailable identity in tooltips/accessibility text. It never appends a provider display name to child rows. Request-state text never claims task completion. Request flights retain the original session source endpoints. Original-to-extraction parity, extraction-to-session-patch parity and nested-row styling comparisons are separate checks. See the extraction manifests and [provenance](native-copy-provenance.md) for the exact boundaries and data/privacy adaptations.

UI uses classic local scripts and fixed relative service assets. The small parent bridge sends `{magpie:1,id,method,params}`; source-checks `event.source===parent`; and receives `{magpie:1,id,result|error}`. Launcher setup uses plugin options writes only. The service reacquires options/theme/visibility, never re-resolves launcher's `hello.service`, and keeps credentials only in memory and API Authorization. Its native registration/translation interface is separate from the parent bridge.

The approved native host adapter contract uses protected GET `/api/native-routing` with no scope/URL/query forwarding. It consumes the cached projection, pauses on hidden parent/document, cancels outdated work, clears sensitive presentation on authorization failure, and re-reads options without automatic credential rotation. Generation/instance and cancellation guards reject obsolete responses. Native request focus/replay are presentation only and never reissue a request.

There is no session dropdown, history-period selector, custom Details drawer or per-request source card in this selected upper block. Legacy scoped/history API contracts remain available but are not presented as native upper-block controls. Native replay/folds/mask preferences are frame-local and any browser storage access is guarded; the sandbox is not weakened for persistence. Inventory-dependent statements and excluded editor links cannot pretend that missing data/configuration actions are supported. Production must not serve pristine upstream/test-only renderer copies.
